## 🚀 Key Features

1. **Instant Onboarding Without Sign-Ups**
   - Learners simply enter their **Full Name**, optional Roll Number, and Department/Branch to personalize their workspace.
   - Progress, solved challenges, badges, and credentials are saved locally in real time.

2. **Full Multi-Language IDE (C, C++, Java, Python)**
   - All 34 Inclass and Postclass curriculum problems solved and verified with complete code.
   - In-browser simulated compiler and test runner with diagnostics, multi-vector validation, and custom input testing.
   - Real-time **Time Complexity** ($O(...)$) and **Memory Space Complexity** metrics for every solution.

3. **Step-by-Step Interactive Visualizer**
   - Step forward, step backward, and autoplay algorithm simulations with adjustable speeds (0.5x, 1x, 2x).
   - Array pointer animations, graph connectivity topologies, and live state inspectors.

4. **Patterns Identification & Remembering Tips and Tricks**
   - Algorithmic architectural justification for each problem.
   - Numbered tips, mental hooks, algebraic shortcuts, and common pitfalls to avoid.

5. **Official QR-Verified Certificates & Badges**
   - Issues personalized JIET Certificates of Excellence.
   - Real dynamic SVG QR code encoding live verification URL.
   - In-app verification portal validating authenticity.
   - Clean printable layout with landscape optimization.

## 📚 Curriculum Problems Covered (34 Problems)

- **Module 1: Graphs & City Networks**
  - *Inclass*: City Transport Network, Constructing a Social Network Graph, City Transportation System
  - *Postclass*: Constructing a Weighted Graph, Exploring City Routes, City Infrastructure Planning
- **Module 2: Arrays, Matrices & Scanning**
  - *Inclass*: Merging Two Inventory Lists, Transposing the Garden Layout, Pangram Check for Automated Book Scanner System
  - *Postclass*: Checking Palindromic Names, Consolidating Stock Information
- **Module 3: Math, LCM & String Mechanics**
  - *Inclass*: Clock Mechanics, Calculating Task Synchronization Interval Using LCM, Reversing Strings for Data Processing
  - *Postclass*: Checking Palindromic Customer IDs, Calculating the Number of Ways
- **Module 4: Number Theory & Intervals**
  - *Inclass*: Prime Security Checkpoints, The Great Divider
  - *Postclass*: Powering the Machine: Subarray LCM Check, Smart Grid Configuration: Identifying Valid Time Intervals
- **Module 5: Ranges, Factors & Precision**
  - *Inclass*: Odd Count Detector in a Given Range, Trailing Zeros in Factorial Count
  - *Postclass*: Prime Factorization of a Number, Glowing Stones: Count of Perfect Squares in a Range
- **Module 6: Two Pointers & Signal Arrays**
  - *Inclass*: Library Phrase Checker: Is It a Valid Palindrome?, Reverse Vowels in Usernames
  - *Postclass*: Identify Zero-Sum Triplets in an Array, Process and Sort Signal Strength Squares
- **Module 7: Chunked Processing & Palindromes**
  - *Inclass*: Reverse Characters in Timed Chunks, Data Stream Realignment
  - *Postclass*: Counting Special Palindromic Substrings, Reverse Characters of Each Word in a Sentence
- **Module 8: Binary Search & Advanced Sorting**
  - *Inclass*: Treasure Hunt: Searching in a Rotated Map, Efficient Price Sorting for an E-Commerce Sale using Quick Sort
  - *Postclass*: Log Analysis: Finding First and Last Occurrence of an Event, Sorting Student Scores using Merge Sort

## 🛠️ Pushing to Your GitHub Repository

To push this project to your GitHub account:

```bash
# 1. Initialize git (if not already done)
git init
git branch -M main

# 2. Stage and commit all files
git add .
git commit -m "Initial commit: JIET CONNECT coding platform"

# 3. Create a new repository on GitHub (e.g. jiet-connect)
# 4. Link your remote repository:
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPOSITORY_NAME>.git

# 5. Push to GitHub:
git push -u origin main
```

*(A ready-to-use GitHub Actions workflow is provided in `.github/workflows/deploy.yml` that will automatically deploy your site to GitHub Pages whenever you push to `main`!)*
